Application icons now use 128-pixel Windows resources for clearer detail on high-DPI displays.

- Fixes the small icon extraction that caused pixelated browser icons.
- Preserves icon transparency and verifies high-resolution resource selection with a native regression test.
- Redraws the first README flow icon and expands the introduction with setup and routing examples.

Download `AudioFlow_0.1.2_x64-setup.exe` below, or check for updates in AudioFlow settings. Restart AudioFlow after updating to refresh application icons.

Browser tabs sharing an audio process share one output. Some apps need playback restarted after an output change. See the [validation record](https://github.com/hazavi/AudioFlow/blob/v0.1.2/VALIDATION.md) for tested behavior and remaining checks.
