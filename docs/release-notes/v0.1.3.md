Adds security restrictions and improves navigation feedback.

- Blocks external navigation and popups in the app window, narrows native permissions, strengthens the content security policy, and freezes the frontend object prototype.
- Keeps signing secrets scoped to the release signing step and pins workflow actions to immutable commits.
- Updates vulnerable test dependencies and adds Git history secret scanning and recurring dependency audits.
- Adds an accessible GitHub icon button to the top bar, pointer cursors for interactive controls, and technology badges in the README.
- Fixes Windows update and uninstall failures by checking the installed app's exact process path. File scanners are excluded from the running-app check. Update installation waits for the app to exit, and uninstall requests a graceful exit from its tray process.
- Moves audio-worker shutdown off the UI thread and combines download, verification, installation, and restart after one update confirmation.

Download `AudioFlow_0.1.3_x64-setup.exe` below, or check for updates in AudioFlow settings.

See [security details](https://github.com/hazavi/AudioFlow/blob/v0.1.3/SECURITY.md) for the security boundaries and upstream informational advisories. Browser tabs sharing an audio process share one output. Some apps need playback restarted after an output change.
