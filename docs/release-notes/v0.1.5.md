Fixes routing changes caused by stationary app windows and temporary audio-session gaps.

- Keeps following the same eligible app window when focus changes. Browser audio children share one window selection, including after an audio-process restart.
- Preserves the assigned output while playback sessions disappear or restart. Old preferences are restored on shutdown when restore-on-exit is enabled.
- Excludes tool windows from routing. Moving the tracked app window between monitors still changes its output.

Validated with 15 Rust tests, including new worker regression tests, 15 frontend tests, and a production frontend build.

Download `AudioFlow_0.1.5_x64-setup.exe` below, or check for updates in AudioFlow settings. Browser tabs sharing an audio process still share one output.
