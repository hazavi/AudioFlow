Fixes flickering output labels, shared browser monitor decisions, quiet speaker tests, and delayed automatic update detection.

- Shows active playback outputs instead of mixing them with old idle sessions. Output ordering is stable, and idle apps show "No active playback"; their session history is available in details.
- Shares monitor history across browser audio processes so a new child cannot request a competing speaker near a display boundary.
- Makes the speaker test about 12 dB louder and extends it to 650 ms, with smooth fades.
- Checks for updates automatically when settings load and every five minutes, including in the tray. Failed checks retry after a minute. Installation still asks for confirmation.

Validated with 18 Rust tests, 20 frontend tests, and a production frontend build.

Download `AudioFlow_0.1.6_x64-setup.exe` below, or update through AudioFlow settings. This version enables the shorter automatic check interval for future releases.
